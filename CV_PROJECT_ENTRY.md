# CV-ready project entry

**Newsroom AI Benchmark | AI Product Evaluation & Experimentation**  
*Personal Project | Python, scikit-learn, NLP, Model Evaluation | November 2026*

- Designed a reproducible benchmarking framework to compare rule-based news tagging, TF–IDF + Naive Bayes and TF–IDF + Logistic Regression using the same labelled headline dataset.
- Evaluated 100 **synthetic** test headlines using accuracy, precision, recall, macro F1, latency, repeat consistency and error analysis; best initial result: **89% accuracy / 0.889 macro F1**.
- Produced experiment scorecards, failure-mode analysis, a blinded human-review template and optional LLM comparison integration to inform AI product pilot decisions.

**Accuracy note:** This entry reports a working synthetic-data demonstration. Real AG News evaluation, actual LLM API comparison and independent human agreement **have not been completed**; do not claim them. Update this entry after running them.
